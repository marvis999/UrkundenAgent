## Der Kreis

```
pruefen   → Befunde und Vorschläge durchgehen
anfordern → Korb hat Positionen           → Anforderung öffnen
warten    → Anforderung gesendet          → Nachfassen | Rückmeldung ist da
eingang   → neue Unterlagen liegen vor    → Durchlauf N starten
analyse   → läuft, Fortschritt je Dokument
→ zurück auf pruefen, Durchlaufzähler +1
```

Anfordern ist ein Korb, kein Schritt: Knopf an jedem Feld, Zähler im Kopf, ein Schreiben aus den
Positionen erzeugt. Nach dem Senden trägt jedes betroffene Feld „angefordert am …". Jede Position
bleibt an ihr Feld gebunden, damit eingehende Unterlagen wissen, wohin sie zurückkommen. Nach dem
nächsten Durchlauf protokolliert die App je Position, wodurch sie erledigt wurde: erledigt,
teilweise oder offen, mit Dateiname.
